# Security Policy

## Supported versions

Security fixes target the latest release on `main`.

## Reporting a vulnerability

Do not open a public issue and do not include proof-of-concept secrets, credentials, or private data. Use GitHub's private security advisory form:

https://github.com/theopoc/runny/security/advisories/new

Include affected version, reproduction steps, impact, and any mitigation. Maintainers will acknowledge valid reports within seven days and coordinate disclosure after a fix is available.
